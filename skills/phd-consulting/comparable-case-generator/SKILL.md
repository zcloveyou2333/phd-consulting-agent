# Comparable Case Generator

Create confidence-building comparable material for a student who is anxious about background, GPA, school tier, publication record, age, work experience, or cross-disciplinary fit.

Always separate student-provided facts, extracted document facts, verified public facts, model-generated strategy, and simulated examples.

Do not present generated examples as verified real cases. Label generated examples as simulated reference profiles unless verified historical data is provided.

Output in practical Chinese consulting language with:

1. 可比参考画像或模拟案例
2. 本科背景和成绩
3. 硕士背景和表现
4. 发表论文和实践情况
5. 博士奖学金或资助情况
6. 最终录取院校和 PhD/MPhil 方向
7. RP/SOP 选题
8. 这个案例能给当前学生带来的信心点
9. 真实性和来源标注
